# Kufar Scraper & Archiver

Консольное приложение для синхронизации, локального архивирования и экспорта объявлений с торговой площадки Kufar.

Проект предназначен для сохранения истории объявлений пользователя (включая активные и закрытые лоты), извлечения подробных характеристик товаров со страниц площадки и последующей выгрузки данных в табличные форматы.

---

## Функциональность

- **Синхронизация через API**: пакетное получение объявлений профиля пользователя.
- **Извлечение данных из HTML**: парсинг подробного описания и технических характеристик со страниц объявлений с очисткой от HTML-разметки.
- **Локальное хранилище данных (SQLite + SQLAlchemy 2.0)**:
  - Идемпотентное сохранение и обновление записей (`upsert`).
  - Сохранение истории цен и статусов без потери ранее загруженных описаний.
- **Экспорт в Excel (`.xlsx`)**: формирование отчётов с форматированием заголовков и автоподбором ширины столбцов с использованием библиотеки `openpyxl`.
- **Обработка сетевых ошибок**: валидация ответов сервиса, обработка ограничений частоты запросов (rate limiting) и диагностика сетевых сбоев.
- **Интерактивный интерфейс**: текстовое консольное меню для управления операциями синхронизации и выгрузки.

## Стек технологий

- **Язык**: Python 3.14+
- **Управление зависимостями и окружением**: [uv](https://github.com/astral-sh/uv)
- **Сетевой клиент**: [HTTPX](https://www.python-httpx.org/)
- **ORM / СУБД**: [SQLAlchemy 2.0](https://www.sqlalchemy.org/) (SQLite)
- **Экспорт данных**: [openpyxl](https://openpyxl.readthedocs.io/)
- **Тестирование**: [pytest](https://docs.pytest.org/)
- **Статический анализ и форматирование**: [Ruff](https://docs.astral.sh/ruff/), Basedpyright

## Установка и запуск

### 1. Клонирование репозитория и установка окружения

```bash
git clone git@github.com:vasili-sikora/kufar_scraper.git
cd kufar_scraper

# Установка зависимостей с помощью uv
uv sync
```

### 2. Конфигурация переменных окружения

Создайте файл `.env` в корневой директории проекта:

```ini
# Токен авторизации Kufar (Bearer токен)
KUFAR_TOKEN=ваш_токен_здесь

# Путь подключения к базе данных (опционально, по умолчанию data/kufar.db)
# DB_URL=sqlite:///data/kufar.db
```

### 3. Запуск приложения

```bash
python src/main.py
# или
uv run python src/main.py
```

Пример интерфейса:
```text
Выберите действие:
1. Синхронизировать объявления
2. Показать объявления из базы
3. Экспортировать в Excel
q. Выход
```
