# Kufar Scraper & Archiver

Сервис синхронизации, отслеживания истории изменений и экспорта объявлений с торговой площадки Kufar.

Приложение сохраняет состояние объявлений профиля пользователя в реляционную базу данных (PostgreSQL / SQLite), фиксирует динамику цен и статусов, предоставляет интерфейсы управления через Telegram-бота и CLI, а также выполняет выгрузку данных в Google Таблицы и формат Excel.

---

## Функциональность

- **Синхронизация данных**:
  - Пакетное получение активных и архивных объявлений через API площадки.
  - Извлечение расширенного описания со страниц лотов с обработкой ограничений частоты запросов (rate limiting).
  - Фоновый планировщик задач для периодической автоматической синхронизации по расписанию.
- **Хранение данных и аудит изменений**:
  - Идемпотентное сохранение и обновление записей (`upsert`).
  - Фиксация истории изменений цен, статусов и описаний с сохранением временных меток каждого события.
  - Управление схемой базы данных с помощью миграций Alembic.
- **Интерфейсы взаимодействия**:
  - **Telegram-бот**: просмотр объявлений, принудительный запуск синхронизации, просмотр истории по идентификатору лота, выгрузка отчетов. Авторизация по белому списку идентификаторов пользователей.
  - **Интерактивный CLI**: терминальное меню для ручного управления операциями и локального просмотра данных.
  - **Неинтерактивный режим (`--cron`)**: запуск синхронизации и экспорта без пользовательского интерфейса для работы под управлением системных планировщиков (cron, systemd timer).
- **Экспорт данных**:
  - **Google Таблицы**: пакетная запись через API с форматированием заголовков и разделением на листы объявлений и истории изменений. Поддержка аутентификации через сервисный аккаунт из переменной окружения.
  - **Microsoft Excel (`.xlsx`)**: формирование локальных отчетов со стилизацией ячеек и автоподбором ширины столбцов.
- **Логирование**:
  - Раздельные потоки логирования для CLI, бота и фоновых задач.
  - Ротация файлов журналов с ограничением размера и глубины архива.

## Стек технологий

- **Язык**: Python 3.14+
- **Менеджер зависимостей**: uv
- **Сетевой клиент**: HTTPX
- **ORM и драйвер базы данных**: SQLAlchemy 2.0, psycopg 3
- **Миграции базы данных**: Alembic
- **Фреймворк Telegram-бота**: aiogram 3
- **Интеграция с таблицами**: gspread, openpyxl
- **Тестирование**: pytest
- **Статический анализ и форматирование**: Ruff

## Установка и запуск

### 1. Клонирование репозитория и установка зависимостей

```bash
git clone git@github.com:vasili-sikora/kufar_scraper.git
cd kufar_scraper

# Установка зависимостей в виртуальное окружение
uv sync
```

### 2. Настройка конфигурации

Создайте файл `.env` в корневом каталоге проекта на основе `.env.example`:

```ini
# Авторизация Kufar
KUFAR_TOKEN=your_kufar_token

# Telegram-бот
TELEGRAM_BOT_TOKEN=your_bot_token
TELEGRAM_USER_ID=your_telegram_id

# Подключение к базе данных
DB_URL=postgresql+psycopg://user:password@host:port/dbname?sslmode=require
# Для локальной SQLite: sqlite:///data/kufar.db

# Экспорт в Google Таблицы
GOOGLE_SPREADSHEET_ID=your_spreadsheet_id
# Путь к файлу ключа сервисного аккаунта...
GOOGLE_SERVICE_ACCOUNT_FILE=google_credentials.json
# ...или содержимое JSON-ключа в виде строки:
# GOOGLE_SERVICE_ACCOUNT_JSON={"type": "service_account", ...}

# Интервал автосинхронизации в боте (в часах, 0 для отключения)
CRON_INTERVAL_HOURS=3
```

### 3. Применение миграций базы данных

```bash
uv run alembic upgrade head
```

### 4. Варианты запуска

#### Интерактивный режим (консольное меню и фоновый бот)
```bash
uv run python src/main.py
```

#### Запуск Telegram-бота
```bash
uv run python src/telegram.py
```

#### Автономный запуск задачи синхронизации (cron / systemd timer)
```bash
uv run python src/main.py --cron
```

## Развертывание в Docker

Сборка образов и запуск сервисов с помощью Docker Compose:

```bash
docker compose up -d --build
```

Конфигурация включает два сервиса:
- `bot` — процесс Telegram-бота с обработкой входящих команд и внутренним циклом планировщика.
- `cron` — фоновый контейнер с периодическим вызовом `src/main.py --cron`.
